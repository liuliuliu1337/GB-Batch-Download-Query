# GB标准文档下载查询器

该工具用于批量下载中国国家标准（GB）文档，通过模拟网页访问、处理验证码后自动化获取标准文档PDF。
-----------------------------------------------------------
本工具基于 https://github.com/suwadaimyojin/gb-downloader 二开
-----------------------------------------------------------

## 功能特点

- 自动获取与维护会话(Session)
- 使用OCR技术自动识别并通过验证码验证
- 根据txt文件批量查询并导出标准号信息 标准号、日期等
- 根据txt文件批量下载PDF文件

## 工作流程

1. **获取会话ID**：首次访问网站获取JSESSIONID，保持会话连续性
2. **处理验证码**：获取、识别并提交验证码
3. **批量搜索PDF文件**：批量搜索GB文件信息（批量查询）
4. **批量下载PDF文件**：将搜索的页面进行识别并批量下载PDF文档

## 快速开始
- pip3 install -r requirements.txt
- python main.py
